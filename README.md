# SmartCut — прошивка устройства

Прошивка ESP32 для умного слайсера: управляет конвейером и ШВП с ножом, показывает состояние на сенсорном экране и принимает команды от Android-приложения [SmartCutApp](https://github.com/YoruKodama/SmartCutApp) по MQTT.

## Возможности

- Цикл нарезки: полный круг конвейера, затем нож вниз по ШВП, затем вверх.
- Запуск с экрана устройства или по команде из приложения.
- Аварийная остановка кнопкой «СТОП» или командой из приложения.
- Приложение присылает шаг рецепта (продукт, вид нарезки, граммы), устройство показывает его и ждёт подтверждения на экране либо стартует само при автоподтверждении.
- Русский интерфейс: этап цикла, прогресс, индикаторы Wi-Fi и MQTT.

## Аппаратная часть

| Узел | Компонент |
|---|---|
| Контроллер | ESP32 |
| Конвейер | мотор, драйвер L298N (скорость через ШИМ) |
| ШВП | шаговый двигатель NEMA 17 |
| Экран | 3.5" SPI TFT 480×320 (ILI9488) |
| Сенсор | XPT2046, подключён отдельными пинами (программный SPI) |

Распиновка находится в начале [src/main.cpp](src/main.cpp) и в [platformio.ini](platformio.ini).

## Как работает цикл

```
Ожидание → (подтверждение шага) → Конвейер → ШВП вниз → ШВП вверх → Готово → Ожидание
```

Круг конвейера отмеряется по времени, ход ШВП — по числу шагов. Параметры цикла (время круга, скорость, число шагов, направление) заданы константами в начале `src/main.cpp`.

## Связь с приложением (MQTT)

| Топик | Направление | Назначение |
|---|---|---|
| `smartcut/cmd` | приложение → устройство | команды |
| `smartcut/status` | устройство → приложение | состояние |

Если в приложении задан ID устройства, топики имеют вид `smartcut/<id>/cmd` и `smartcut/<id>/status`.

Команды:

```json
{"action": "recipe_step", "product": "Морковь", "cut": "sticks", "grams": 200, "autoconfirm": false}
{"action": "clear_step"}
{"action": "stop"}
```

`cut` принимает `sticks`, `shred` или `grate`. Статус публикуется при смене этапа и раз в 5 секунд:

```json
{"state": "idle", "stage": 0}
```

`state`: `idle`, `waiting_confirm`, `running`, `done`.

## Конфигурация

Параметры сети и брокера не хранятся в репозитории. Шаблон лежит в [include/secrets.example.h](include/secrets.example.h); рабочий файл `include/secrets.h` создаётся локально и добавлен в `.gitignore`.

## Структура

```
platformio.ini            сборка и настройки дисплея
include/secrets.example.h шаблон настроек сети
include/font_ru.h         шрифт с кириллицей (генерируется)
src/main.cpp              прошивка
tools/gen_font.py         генератор шрифта
```

Сборка выполняется через [PlatformIO](https://platformio.org/).
